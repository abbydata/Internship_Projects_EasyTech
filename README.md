# Internship Projects

This repository contains projects completed during my internship with EasyTech Academy.

The academy runs an initiative called EasyTech Talent, a monthly data analytics challenge designed to help participants build practical, industry-relevant skills through hands-on projects.

These projects are based on real-world datasets and provide opportunities to apply data analysis skills using tools such as:

* Excel
* Power BI
* SQL

Through these challenges, I am able to strengthen my skills in data cleaning, analysis, visualization, reporting, and problem-solving while working with actual datasets and business-focused questions.

This repository serves as a collection of my projects, learning progress, and analytical work completed during the internship program.
